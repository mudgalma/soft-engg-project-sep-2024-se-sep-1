This project was developed as part of the coursework for the **BS in Data Science and Applications at IIT Madras**.

## 🌐 Live Application

You can access the deployed application here:

**https://soft-engg-project-sep-2024-se-sep-1-1sylj1nzp-trackie.vercel.app/**

## 🚀 About the Application

Trackie is a role-based academic/project tracking platform built to support:

- **Admin** management and oversight
- **Instructor** workflows
- **Student** participation and tracking

The project includes both frontend and backend components, and is built primarily using:

- Vue
- Python
- CSS
- TypeScript
- HTML
